# 🌐 Armada

**Educational project** – a six-page website for a fictional printing company.  
This project demonstrates basic front-end development skills using HTML and CSS.

## ✨ Features
- 6 pages: Home, Services, About Us, Contacts, Portfolio, Production  
- Built with **HTML5** and **CSS3**  
- Layout implemented with **Flexbox**

## 📂 Project Structure
├── index.html # Home page
├── services.html # Services
├── about.html # About us
├── contacts.html # Contacts
├── portfolio.html # Portfolio
├── production.html # Production
├── css/
│ └── style.css
└── img/

## ⚙️ Technologies Used
- HTML5
- CSS3 (Flexbox)
